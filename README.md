# world-grasp

世界監視・把握プラットフォームのプロトタイプ。
火星EVA計画アプリ **WALKBACK** の「あとどれだけ動けて、いつまでに帰れば安全か」という帰還判定の考え方を、複数の移動体をまとめて把握する形に拡張する。

## コンセプト

- 対象は **地球がメイン、火星モード付き**
- 地図上の全ユニット（巡回チーム、ドローン、車両、船外活動クルー等）について、次を常時計算して一画面で把握する
  - 現在位置と移動経路
  - 残リソース（燃料／電池／酸素・冷却水など、ユニット種別ごとに定義）
  - **帰還可能範囲（return envelope）** と帰還限界時刻（point of no return）
- ハザード層（洪水・土砂等のハザード情報、災害イベント）と重ねて、危険圏内のユニットや帰還マージンが閾値を切ったユニットを即座にアラートする

## 由来と再利用

- WALKBACK（NASA Space Apps 2026 提出作品）の帰還判定ロジックが核
- 地球版の歩行計画エンジン（地形コスト、ハザード回避、帰路計算）は walkhome プロジェクトで育てた Rust コア → WASM を再利用する想定

## 構成（予定）

- `core/` — 移動コスト・帰還判定エンジン（Rust → WASM）
- `web/` — 地図UI（React + Vite + Leaflet）：ユニット一覧、帰還可能範囲、アラートパネル、時間再生
- データ層：標高タイル、ハザードマップ、実イベントフィード（NASA EONET 等）

## ステータス

プロトタイプ作成中。まず触れる形として、シミュレーションでユニットが動き、帰還マージンとアラートが更新される画面から作る。
