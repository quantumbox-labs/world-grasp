# 提出ルール要点（NASA Space Apps 2026 ローカル）

出典: LOCAL LEAD ONLY - Project Submission Guide（PDF, 8p）

## 締切
- 受付開始: **11/14(土) 09:00** 現地時間
- **札幌ローカル締切: 11/15(日) 14:00 JST** ← 実質の最終締切（14:30〜発表・審査、16:30 表彰/Global Nominee）
  - 社内目標: 13:00 提出完了
- グローバル締切: 11/15(日) 23:59 現地時間 — 過ぎたら審査対象外
- 締切まで何度でも再提出OK（最後に保存した版が審査対象）

## 必須
- [ ] フォームは**全部英語**
- [ ] **NASAデータ/リソースを最低1つ**使う（グローバル賞の条件）
  - JAXA など宇宙機関パートナーのデータ併用は推奨
- [ ] デモ: **動画30秒以内** or **スライド7枚以内**（タイトル・イントロ込み）— 超過はグローバル審査対象外
  - 動画は英語以外で話してもよいが**英語字幕必須**／スライドは英語
  - スライドに: チーム名・メンバー名・選んだ課題
- [ ] デモ・最終成果物は**ログイン不要の公開リンク**（YouTube / GitHub / Drive 等）。シークレットウィンドウで確認
- [ ] 18歳未満の人物の画像・動画・音声を含めない
- [ ] チーム全員が同じローカルイベントに参加確定
- [ ] 利用規約チェック + オリジナル確認チェック → 「審査のために提出」

## フォーム項目
1. プロジェクト名
2. 概要（何を作った／どう解決／なぜ重要）
3. デモへのリンク
4. 最終プロジェクトへのリンク
5. 詳細説明（機能・仕組み・利点・目標・使用ツール/言語）
6. **NASA・宇宙機関パートナーのデータ**（何をどう使ったか）
7. 参考文献（データ・コード・画像すべて）
8. AI（SI）利用の申告

## AI利用ルール（重要）
- AIツールの利用は可。ただし**課題解決のアイデア自体をAIに考えさせるのは禁止**
- AI生成物に **NASAロゴ・旗・ミッション記章を入れない／改変しない**
- AI生成の画像・動画 → **透かし必須**
- AI生成の音声・コード・データ → 説明文とメタデータに明記

## 審査基準（5つ）
インパクト / 創造性 / 妥当性 / 関連性 / プレゼンテーション

## 30秒動画の構成例
- 0:00 名前・チーム名
- 0:02 取り組む課題と理由
- 0:05 プロジェクト名＋キャッチフレーズ
- 0:10 仕組み・画面・NASAデータの使い方
- 0:20–0:30 未来像

## その他
- プロジェクトページに直接上げられるのは画像（JPG/PNG/GIF, 10MBまで）だけ
- 独自サイトを作る場合は FortiGuard Web フィルタ分類の申請を推奨（任意）
