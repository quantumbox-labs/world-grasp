北海道の1年で、月面基地の訓練計画を組む。

One year in Hokkaido = a full rehearsal campaign for a Moon base.
月の基地候補地（NASA の Artemis III 候補など）を1つ選ぶ。
「着陸・氷の採掘・歩行・縦穴・建設」の試験ごとに、北海道のどこで、何月にやればいいかが出る。
同時に「ここでは再現できないこと」（重力1/6、真空、−200℃級の寒さ など）も必ず出る。似ている点と違う点の両方をデータで示す、という課題文の要求にそのまま答える。

結局なにができればいいか

これができれば提出できる（5つ）

  1. 月の基地候補（Artemis III 候補など）を地図で選べる
  2. 試験ごと（着陸・氷・歩行・縦穴・建設）に、北海道の上位地点が5軸の内訳つきで出る
  3. 試験ごとに「北海道では再現できないこと」が数字つきで出る（例：温度差 約175 K）
  4. 使った NASA データの出典が画面とフォームに書ける（LRO・MODIS・Artemis 候補地）
  5. 公開リンクで開けて、30秒動画で伝わる

1〜3が段1（今日19時まで、既存のコードとデータで作れる）。4・5は必ずやる。

ここが夢（ギリ届くかどうか）

  1. 季節スライダーと1年の訓練カレンダー。スライダーを動かすと北海道の地図の順位が入れ替わり、「何月にどこで何の試験」が12ヶ月の表になる（段2・夢の本体）
  2. 同じ坂・同じ距離の練習ルートを北海道に出す。月や火星で引いた道と似た道が北海道の地図に出る。火星（#11）側でチームが選んだ夢と同じもので、2つの課題が1本につながる（今は未来像。段3と差し替え候補）
  3. 北海道のどこでもクリックで即スコア。14地点以外でも地形の点数とできない試験が出る（段3）

一言「北海道の1年で、月面基地の訓練計画を組む。」は夢1が実現して初めて言い切れる。夢1が間に合わなければ、1月と8月の2時点で見せる。

スコアの仕組み：5つの軸を足し合わせる

各軸を 0〜1 で出し、試験ごとの重みで足して 0〜100 点にします。計算は crates/analog-core/src/scoring.rs に実装済み。5軸の採用は Drive の調査（ShadowAstra Atlas）に従っています。

4

季節で何が変わるか（夢の本体）

今のスコアは「1年の最小と最大」を1つの値にまとめています。これを月ごとに分けると、季節スライダーと訓練カレンダーが作れます。

旭岳の正午の太陽の高さ（月別）と、月の南極の比較

緯度と日付だけで計算できるのでデータ取得は不要（今のコードに南中高度の計算が既にある）。月の南極はどの月も 3〜6° なので、北海道で一番近いのは冬至前後。これ自体が「再現できない差」の見せ方になります。

軸ごとの「今」と「段2のあと」

軸今あるデータ段2で足すもの季節で変わる？

「変わらない軸もある」と明記するのが妥当性の加点ポイント。温度・積雪の月別データは NASA の GIBS / Earthdata から取る想定で、取り出し口は未検証（クラウドからは届かないので Mac 側で実行）。

4.6

配る形：本命は Web、Tauri はおまけ

提出ルールは「ログイン不要の公開リンク」。審査員はダウンロードやインストールをしない前提で考えるのが安全です。

Web（静的サイト）本命

React ＋ WASM をそのまま GitHub Pages 等に置く。リンクを踏めばすぐ動く。mise run build の web/dist がそのまま使える。

必要なこと：git remote を作って公開設定。シークレットウィンドウで確認。

Tauri デスクトップおまけ

同じ画面と同じ Rust の計算がネイティブで動く。「現場（野外試験地）にも持ち出せる」という説明に使える。

注意：地図タイルはネット経由なので完全オフラインではない。配布は GitHub Releases にビルドを置く形。

どちらも同じコード

計算は Rust コア1つ（crates/analog-core）。Web は WASM で、Tauri はネイティブで呼ぶだけなので、作業が二重にはならない。

スライドでは「Web で今すぐ試せる／デスクトップ版もある」と一言添える程度で十分。

用語

アナログ（Earth analog）月や火星の環境に似ていて、装備や手順の練習ができる地球上の場所。
Artemis IIINASA の有人月着陸計画。月の南極付近に着陸候補地域が選ばれている。
EVA船外活動。宇宙服を着て外を歩く作業。
ISRU現地資源利用。月の氷から水や酸素を作るなど。
永久影（PSR）太陽の光が一度も当たらないクレーターの底。氷が残っていると考えられている。
レゴリス月や火星の表面を覆う細かい砂や岩くず。
南中高度正午の太陽の高さ（地平線から何度か）。
K（ケルビン）温度の単位。0℃ ≒ 273 K。76 K は約 −197℃。
MODISNASA の地球観測衛星 Terra / Aqua のセンサー。地表温度・積雪・植生を毎日観測。
GIBS / TrekNASA の地図タイル配信。GIBS は地球、Solar System Treks は月・火星。キー不要。
NDVI植生の濃さの指数。0 に近いほど植物が無い。
LOLA / Diviner月探査機 LRO の観測装置。LOLA は標高、Diviner は地表温度。

提出ルールで「アイデア自体をAIに考えさせる」のは禁止です。このページはチームの資料と課題文の要素を組み合わせたたたき台なので、採るか・どこを変えるか・一言の言葉はチームで決めてください。公開リンク用の git remote もまだ無いので、置き場所（GitHub Pages 等）も早めに決める必要があります。

チームで決めること

この方向で行くか行くなら段1の実装と月別データ取得を並行で始めます。
一言「北海道の1年で、月面基地の訓練計画を組む。」はたたき台。チームの言葉に。
